Failure scenarios: what happens when one party or component fails

A grade says how a token is built. This page says what happens when one of its parts fails: your keys are stolen, the custodian goes bankrupt, the company is acquired, the multiplier is set wrong, or a regulator steps in. Each failure mode is put to every issuer in the same words, so you can see which issuers have an answer and which do not. We never invent an outcome. An answer is documented only when the issuer's or a regulator's own document addresses the case and we can quote it. It is inferred when the documents do not address it but the structure implies the answer, and we mark it as our reading. It is litigated when a court, tribunal or regulator decided this or a materially identical case, with the case cited. It is unknown when we looked and the documents do not say; we then record where we looked, because the gap is a finding. An empty cell means nobody has answered that question for that issuer yet, and it is drawn as empty.

What the colours mean

    Which issuers have documented answers

    Per issuer, how its answers to all the questions split by status, sorted by how many are documented (answered from the issuer's or a regulator's own words). Questions nobody has answered for an issuer yet would show as a faded end of its bar. Each bar opens that issuer's column of the matrix; the dates are when the answers' sources were read.

    The matrix

    One row per question, one column per issuer. Tap a cell to read the answer: the outcome, the quote it rests on, the source with its locator and the date it was read. The status filter keeps the questions in which at least one issuer's answer has one of the statuses you picked, and marks those cells. It does not hide individual cells, so every row stays complete. The actor filter keeps the questions about one party (holder, custodian, token program and so on), and an issuer link from a dossier keeps only that programme's column. All filters are stored in the URL, so you can share a filtered view as a link.
